# Security Policy

Please do not report vulnerabilities by posting secrets, tokens, private Funnel hostnames, or exploit details in public issues.

For a suspected vulnerability, contact the repository owner privately through GitHub. Include the affected version, impact, reproduction steps, and sanitized evidence.

For immediate containment of a leaked Bearer token: stop MCP Xellen, replace the local token file with a newly generated random token, restart the gateway, and upload the new token only to the intended trusted client session.
